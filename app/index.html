GetawayGenius

A mobile vacation planning application for Android

⬇️ Download APK
Android 8.0+ Java Room Database Firebase Auth SQLite
⚠️ Requirements: Android 8.0 or higher  |  Active internet connection required for login and account creation

Getting Started

  1. Open the application by tapping the airplane icon
  2. Create an account or log in with your existing credentials
  3. Tap "Build your perfect vacation!" to get started

Features

🏖️ Vacations

  • Add unlimited vacations
  • Track title, hotel & dates
  • Set start & end alerts
  • Share via email, SMS, or clipboard

🗺️ Excursions

  • Add excursions to vacations
  • Dates validated within vacation
  • Set reminders for each excursion

🔍 Search

  • Search vacations & excursions by keyword

📊 Reports

  • Generate date-range reports
  • View lodging, dates & excursion count
  • Timestamped report generation
