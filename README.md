# Getaway Genius
A mobile vacation planning application built for Android using Java, Room Database, and Firebase Authentication.

## Requirements
Android 8.0 and higher
Active internet connection required for login and account creation

## Getting Started
Use this app to plan your next vacation! Keep track of dates
and any fun excursions you have planned.

1. Open the application by tapping the airplane icon
2. Create an account or log in with your existing credentials 
3. Tap "Build your perfect vacation!" to get started

## Vacations
- Add as many vacations as you want
- Each vacation requires a title, hotel, start date, and end date
- Dates must be entered in MM/dd/yy format
- A vacation cannot be deleted until all associated excursions are removed
- Set alerts for vacation start and end dates
- Share vacation details via email, clipboard, or SMS

## Excursions
- Add as many excursions as needed to each vacation
- Each excursion requires a title and date
- Excursion dates must fall within the vacation dates
- Set alerts to remind you of upcoming excursions

## Search
- Search for vacations and excursions by keyword from the Vacations page

## Reports
- Generate date-range reports from the Vacation Details page
- Reports display vacation name, lodging, dates, and excursion count
- Each report includes a timestamp of when it was generated
